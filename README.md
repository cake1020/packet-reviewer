# Packet Review

브라우저에서 규정·제출서류를 읽어 OpenAI API로 검토보고서를 생성하는 정적 웹앱입니다.

## 보안 모델

- API 키는 브라우저 메모리에만 유지하며 서버로 전송하지 않습니다.
- 문서와 API 요청은 브라우저에서 OpenAI API로 직접 전송됩니다.
- 키를 저장하지 않으며, 페이지를 새로고침하면 사라집니다.
- 배포 시에도 서버 API 라우트나 비밀키가 없습니다.

## 실행

```bash
npm install
npm run dev
```

## 지원 형식

- PDF: 브라우저에서 텍스트 추출
- XLSX/XLS: 브라우저에서 시트·수식·값 추출
- HWPX: ZIP/XML 기반 텍스트 추출
- TXT/MD/CSV: 브라우저에서 직접 읽기
- HWP: 브라우저 추출 한계가 있어 OpenAI 파일 분석을 시도하고, 실패 시 보류 사유로 표시
